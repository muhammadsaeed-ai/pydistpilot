# Support

For usage questions, first check the README, troubleshooting section, and `docs/` guides. Before opening an issue, please include your PyDistPilot version, Python version, operating system, the command you ran, the exit code, and a redacted diagnostic report or terminal output.

- Report reproducible defects with the bug issue template.
- Propose functionality with the feature request template.
- Report suspected security issues privately using the process in `SECURITY.md` rather than publishing exploit details in a public issue.

Never attach credentials, private source code, confidential build logs, or unreviewed reports that may contain local paths or secrets.
